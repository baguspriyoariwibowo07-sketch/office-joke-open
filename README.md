A single one-line joke about office life, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> The birthday card for the manager nobody likes still got 40 signatures. It remains the most collaborative thing this office has ever produced.

## Why this line

- **Office to the core:** a birthday-card signing round — a ritual every office worker has lived.
- **Earned laugh:** the turn reframes forty reluctant signatures as peak collaboration; the punch lands on the last words.
- **Specific detail:** a card, a disliked manager, an exact count of signatures — not a generic grumble about work.
- **Fresh:** the field saturates with printer jokes, meetings-about-meetings and "per my last email"; the birthday card is untouched.
- **Tight:** two short sentences, 142 characters against the 200-character gate, no word cuttable.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
